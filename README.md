### About

I build production ML systems, AI research prototypes, and cloud-native applications that move from experiments to usable software.

Currently pursuing an MSCS in AI at NYU Courant, with 4+ years of experience across computer vision, NLP, data pipelines, full-stack services, and reliability-focused infrastructure.

### Selected Highlights

- **AI research:** Developing Solaris at NYU Courant, an ICML 2026 multi-agent video world model project for action-conditioned Video-DiT under partial observability.
- **Applied computer vision:** Built multimodal MRI brain tumor classification and segmentation models with 91.3% accuracy and 97.1% sensitivity on BraTS.
- **Production NLP:** Shipped a cloud-native text classification service on GCP using DistilBERT, multi-model inference, and automated deployment workflows.
- **Accessibility tooling:** Contributed to Testaro at CVS Health, a web accessibility testing tool presented at the 25th ACM SIGACCESS ASSETS conference.
